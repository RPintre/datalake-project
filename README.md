# datalake-project

Projet fil rouge **Retail Intelligence Platform** (Mastère Dev, Data & IA, IPSSI) : conception d'une plateforme Data Lake pour l'analyse de données retail.

## Avancement

- **Jour 1** : besoin métier, exploration des données et choix d'architecture (UC-01 et UC-02). Voir le dossier [`J1_Retail_Intelligence`](J1_Retail_Intelligence/README.md).
- **Jour 2** : Hadoop, HDFS et Data Lake (UC-03), ingestion avec Apache NiFi (UC-04), avec preuves d'exécution et procédure de reproduction. Voir le dossier [`J2_Retail_Intelligence`](J2_Retail_Intelligence/README.md).
